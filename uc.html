২. অর্ডারের তথ্য

📍 Player ID কোথায় পাবো?
  1. PUBG Mobile খুলে লবিতে যান।
  2. উপরের বাঁ দিকে আপনার প্রোফাইল ছবিতে ট্যাপ করুন।
  3. নামের নিচে ID নম্বর দেখতে পাবেন। পাশের কপি আইকনে চেপে কপি করে এখানে পেস্ট করুন।

গেমের ভার্সন অনুযায়ী জায়গা সামান্য আলাদা হতে পারে। ID শুধু সংখ্যার হয়।

🕙 অর্ডারের সময়: সকাল ১০টা থেকে রাত ১০টা।

⚠️ ভুল UID দিয়ে UC অর্ডার করার পর টাকা ফেরত নেই। অর্ডারের আগে Player ID ভালো করে মিলিয়ে নিন।

কিভাবে অর্ডার করবেন

  1. প্যাকেজ সিলেক্ট করুন ও Player ID দিন।
  2. নির্দেশিত নম্বরে Send Money করুন।
  3. Transaction ID বসিয়ে অর্ডার বাটনে চাপ দিন।
  4. WhatsApp-এ মেসেজ যাবে, পেমেন্ট যাচাইয়ের পর UC টপ-আপ হবে।

সাধারণ প্রশ্ন

কত সময় লাগে?

পেমেন্ট যাচাইয়ের পর সাধারণত ৫–৩০ মিনিট।

ভুল ID দিলে?

অর্ডারের আগে ID ভালো করে মিলিয়ে নিন। ভুল ID-তে পাঠানো টপ-আপ ফেরত দেওয়া সম্ভব নয়।

পাসওয়ার্ড লাগবে?

না। শুধু Player ID লাগে। কাউকে পাসওয়ার্ড বা OTP দেবেন না।
